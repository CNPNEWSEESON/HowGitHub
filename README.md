# 🐙 คู่มือ Git & GitHub ฉบับง่ายๆ (สำหรับมือใหม่)

สอนแบบง่ายที่สุด เข้าใจใน 5 นาที! เน้น 4 คำสั่งหลักที่ใช้บ่อยที่สุด

---

## 🧠 ก่อนอื่น เข้าใจภาพรวมก่อน

ลองนึกภาพว่า Git คือ **"เครื่องบันทึกประวัติงาน"** ของโค้ดเรา
และ GitHub คือ **"ที่เก็บงานออนไลน์"** ที่ให้เราอัปโหลดงานขึ้นไปเก็บ หรือแชร์ให้คนอื่น

```
[คอมพิวเตอร์ของเรา]  <-- push/pull -->  [GitHub (ออนไลน์)]
   (Local)                                  (Remote)
```

---

## 🔑 4 คำสั่งหลักที่ต้องรู้

| คำสั่ง | ทำอะไร | เปรียบเทียบง่ายๆ |
|--------|--------|-------------------|
| `git add` | เลือกไฟล์ที่จะบันทึก | หยิบของใส่ตะกร้า 🛒 |
| `git commit` | บันทึกงาน (สร้างจุด save) | กด Save เกม 💾 |
| `git push` | ส่งงานขึ้น GitHub | อัปโหลดขึ้นคลาวด์ ☁️ |
| `git pull` | ดึงงานล่าสุดจาก GitHub ลงมา | ดาวน์โหลดของใหม่ลงมา ⬇️ |

---

## 📝 ขั้นตอนการใช้งานจริง

### 1️⃣ เริ่มต้นโปรเจกต์ (ทำครั้งเดียว)

```bash
git init
```
> สร้างพื้นที่ Git ในโฟลเดอร์นี้ (เหมือนเปิดสมุดบันทึกเล่มใหม่)

ถ้ามีที่เก็บบน GitHub อยู่แล้ว ให้โคลนลงมาแทน:
```bash
git clone https://github.com/ชื่อผู้ใช้/ชื่อโปรเจกต์.git
```

---

### 2️⃣ แก้ไข/สร้างไฟล์ตามปกติ
เขียนโค้ด แก้ไฟล์ยังไงก็ได้ตามที่ต้องการ 🧑‍💻

---

### 3️⃣ `git add` — หยิบของใส่ตะกร้า

```bash
git add ชื่อไฟล์.txt
```

หรือถ้าจะเอาทุกไฟล์ที่แก้ไขทั้งหมด ใช้:
```bash
git add .
```
> จุด `.` แปลว่า "ทั้งหมดในโฟลเดอร์นี้"

---

### 4️⃣ `git commit` — กด Save พร้อมข้อความ

```bash
git commit -m "แก้ไขหน้าแรกของเว็บ"
```
> `-m` คือใส่ข้อความอธิบายว่าเราทำอะไรไป ควรเขียนสั้นๆ ให้เข้าใจง่าย

---

### 5️⃣ `git push` — ส่งขึ้น GitHub

```bash
git push
```
> ถ้าเป็นครั้งแรกอาจต้องพิมพ์เต็มๆ ว่า:
```bash
git push origin main
```

---

### 6️⃣ `git pull` — ดึงงานล่าสุดลงมา

```bash
git pull
```
> ใช้ตอนที่เพื่อนร่วมทีม (หรือตัวเราเองจากเครื่องอื่น) อัปเดตงานขึ้น GitHub แล้ว เราต้องดึงลงมาก่อนเริ่มทำงานต่อ

---

## 🔁 สรุปวงจรการทำงานที่ใช้ทุกวัน

```
1. git pull        (ดึงของใหม่มาก่อน กันชนกัน)
2. แก้ไขไฟล์
3. git add .
4. git commit -m "ข้อความ"
5. git push
```

จำง่ายๆ ว่า: **pull → แก้งาน → add → commit → push** 🔄

---

## 💡 คำสั่งเสริมที่มีประโยชน์

| คำสั่ง | ใช้ทำอะไร |
|--------|-----------|
| `git status` | เช็คว่าตอนนี้มีไฟล์ไหนแก้ไขอยู่บ้าง |
| `git log` | ดูประวัติการ commit ทั้งหมด |
| `git branch` | ดูว่ามีกิ่งงาน (branch) อะไรบ้าง |
| `git checkout -b ชื่อกิ่ง` | สร้างกิ่งงานใหม่แล้วสลับไปทำ |

---

## ⚠️ ข้อผิดพลาดที่เจอบ่อย

- **ลืม `git add` ก่อน commit** → จะ commit ไม่ได้ผล เพราะยังไม่ได้เลือกไฟล์
- **ลืม pull ก่อนเริ่มงาน** → อาจ push ไม่ได้เพราะมีคนอื่นแก้ไปก่อนแล้ว (เกิด conflict)
- **ลืมใส่ `-m` ตอน commit** → Git จะเปิดหน้าต่างให้พิมพ์ข้อความแทน (งง!)

---

🎉 แค่นี้ก็ใช้ Git/GitHub เป็นแล้ว! ลองฝึกทำตามลำดับ **pull → add → commit → push** ซ้ำๆ จะคล่องเอง
